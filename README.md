## Publicar en GitHub Pages (gratis)

```bash
cd ~/proyectos/portafolio
git init
git add .
git commit -m "Portafolio Aparecé v1"
# crear repo en GitHub: sotonavarrojosue-creator/portafolio (privado NO: Pages necesita público o pro; público ok)
git remote add origin https://github.com/sotonavarrojosue-creator/portafolio.git
git push -u origin main
```

Luego en GitHub → repo → Settings → Pages → Source: `main` / root → Guardar.
URL: `https://sotonavarrojosue-creator.github.io/portafolio/`

> GitHub Pages requiere repo público (o plan pago). El portafolio es público por diseño: es tu carta de presentación.

## Caso de estudio — política de anonimato

- El caso real está **anonimizado** ("Taller mecánico de San José", sin nombre ni teléfono).
- Cuando un cliente **compre** (empezando por Taller M y M), pedirle permiso explícito para usarlo como testimonio con nombre + foto del local → ahí se "desanonimiza" y se suma al portafolio con su consentimiento.
- Argumento de cierre: "Si le gusta, lo sumo a mi portafolio con su taller y le mando clientes."
- Nunca exponer un negocio que no haya contratado (riesgo de que se sienta invadido y corra la voz).
